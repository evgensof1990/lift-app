# Ролик «Лифт» для новых пилотов

`lift-promo.mp4` — видео-презентация (1:17, 720×1280, с музыкой — трек синтезирован, без чужих прав) для отправки в мессенджерах.
Главная идея — «Лифт» забирает рутину: пилот рассказывает, что отнимает время, команда автоматизирует, часы возвращаются на продажи и своё дело.
Прежняя версия (про стратегию) — в истории git.

Скачать: открыть файл на GitHub → кнопка «Download raw file» (стрелка вниз справа).
Папка не входит в сборку сайта и APK.
